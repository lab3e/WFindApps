Installing

  1. Download the .zip file for the program you want.
  2. Unzip it. In File Explorer, right-click the file and choose Extract All. You'll get the program, a README, and the license.
  3. Double-click the program (WCopyfind.exe or WRepeatfind.exe). There's nothing to install. You can keep it anywhere, such as your Desktop or Documents folder.

If Windows says "Windows protected your PC", click More info and then Run anyway. Windows shows this warning for programs that haven't paid for a code-signing certificate, which free programs often haven't. The programs are open source: anyone can read exactly what they do on GitHub.

Reading PDF files

Both programs read PDF files best with the help of pdftotext.exe, a free converter from the Xpdf command-line tools. Download the Windows version, find pdftotext.exe inside (in the bin64 folder), and put it in the same folder as WCopyfind or WRepeatfind. They'll use it automatically. PDFs that are only pictures of pages (scans) contain no text to read; run them through OCR software first.
