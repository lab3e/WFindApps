Reporting a problem or suggesting a feature

Please open an issue on GitHub: {{issues}}. It's free to create a GitHub account. A good report says which program and version you're using (it's in the window's title bar), what you did, what you expected, and what happened instead. If a particular document causes the problem and it isn't confidential, attaching it helps enormously.

Please don't attach documents that are private, such as student papers. The programs keep your documents on your computer; there's no need to share them to get help.

Contributing

WCopyfind and WRepeatfind are open source under the GNU General Public License. Improvements are welcome: see the repository on GitHub for the source code and build instructions.

Research collaborations

These programs can study how language moves through society: between news services, into legislation, across scholarship. Lou Bloomfield is always interested in collaborations that lead to peer-reviewed publications. If you have a project that involves sifting through large collections of documents for reused language, please get in touch through GitHub.
