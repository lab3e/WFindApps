Installing and running it

  1. Download the .zip file above.
  2. Unzip it: right-click the file in File Explorer and choose Extract All. Inside are WRepeatfind.exe, a README, and the license.
  3. Double-click WRepeatfind.exe. There's nothing to install. Keep it wherever you like; to remove it, just delete it.

"Windows protected your PC"? Click More info, then Run anyway. Windows shows this for programs without a paid code-signing certificate, which is common for free software. WRepeatfind is open source, so its code is public for anyone to inspect.

Then follow the user guide.

Sample documents

WRepeatfind-Samples.zip contains a news article with two passages accidentally left in twice, and a three-chapter story with a passage repeated between chapters. The guide shows what to expect.

Reading PDF files

WRepeatfind reads PDF files best with pdftotext.exe, a free converter: download the Xpdf command line tools for Windows from the Xpdf download page, find pdftotext.exe in the bin64 folder, and copy it into the same folder as WRepeatfind.exe. It's usually simpler to check the original Word document instead.

System requirements

  • 64-bit Windows 10 or Windows 11
  • A web browser to view the report

Even a book-length manuscript takes WRepeatfind less than a second. Mac and Linux users can try Wine or a Windows virtual machine.
